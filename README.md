# Foxurrent.

Minimal Roblox studio site with liquid-glass UI.

- Projects (Roblox API)
- Dev Blog & News (images + clickable links)
- Contributors (TG, TikTok, Instagram, Roblox, X, …)
- Privacy (EN + RU), Terms, Cookies banner
- Admin (SHA-256 password hash)

Deploy: static on Vercel or open index.html.
